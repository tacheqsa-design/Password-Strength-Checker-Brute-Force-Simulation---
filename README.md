# 🛡️ Cyber Security Tools: Password Strength Checker & Brute Force Simulator

ეს პროექტი შეიცავს ორ ძირითად პითონის სკრიპტს, რომლებიც გამოიყენება პაროლების უსაფრთხოების ანალიზისა და ჰეშირებული მონაცემების ლექსიკონური შეტევის (Dictionary Attack) სიმულაციისთვის.

---

## 1. 🔑 პაროლის სიძლიერის შემოწმება (Password Strength Checker)

სკრიპტი ამოწმებს მომხმარებლის მიერ შეყვანილ პაროლს 5 ძირითად უსაფრთხოების კრიტერიუმზე და ანიჭებს შესაბამის ქულას (0-დან 5-მდე).

### 📌 ძირითადი კრიტერიუმები:
* *სიგრძე:* მინიმუმ 8 სიმბოლო.
* *დიდი ასოები:* შეიცავს თუ არა მინიმუმ ერთ დიდ ასოს (A-Z).
* *პატარა ასოები:* შეიცავს თუ არა მინიმუმ ერთ პატარა ასოს (a-z).
* *ციფრები:* შეიცავს თუ არა მინიმუმ ერთ ციფრს (0-9).
* *სპეცსიმბოლოები:* შეიცავს თუ არა სპეციალურ სიმბოლოებს (!, @, #, $, % და ა.შ.).

### 📊 შეფასების სისტემა (Verdict):
* *5 ქულა:* STRONG (ძალიან ძლიერი და უსაფრთხო პაროლი)
* *3-4 ქულა:* MEDIUM (საშუალო სიძლიერის პაროლი)
* *0-2 ქულა:* WEAK (სუსტი პაროლი, ადვილად მოსატეხი)

## 2. ⚡ ბრუტ ფორს სიმულატორი (Dictionary Brute Force Simulator)

ეს სკრიპტი ახდენს კიბერუსაფრთხოებაში გავრცელებული „ლექსიკონური შეტევის“ სიმულაციას. ის ორიენტირებულია ციფრობრივი პაროლების სწრაფ გადარჩევაზე.

### ⚙️ როგორ მუშაობს:
1. *მონაცემთა ბაზის ჩატვირთვა:* პროგრამა კითხულობს hashes.txt ფაილს, სადაც მოცემულია პოპულარული პაროლები/ციფრები.
2. *ოპტიმიზებული ჰეშირება:* კითხვის პროცესშივე პროგრამა თითოეულ პაროლს აჰეშირებს *SHA-256* ალგორითმით და ინახავს Dictionary ({Hash: Plaintext}) ობიექტში, რაც ძებნას ხდის მყისიერს ($O(1)$ დროში).
3. *შედარება (Matching):* მომხმარებლის მიერ შეყვანილი პაროლი კონვერტირდება SHA-256 ჰეშში და პროგრამა სათითაოდ ადარებს მას ბაზაში არსებულ ჰეშებს.
4. *ვიზუალიზაცია:* ტერმინალში ფერების (ANSI escape codes) საშუალებით რეალურ დროში ჩანს გადარჩევის (Checking) პროცესი და მცდელობების რაოდენობა.
